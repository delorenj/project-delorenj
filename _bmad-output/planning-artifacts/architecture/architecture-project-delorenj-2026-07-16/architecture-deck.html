01

The paradigm

One named model that loads a whole structure for free — and the single-authority rules that keep two co-equal layers from fighting over the same job.

Layered progressive-enhancement over a single-source-of-truth data core, with a single-authority runtime. One Career Data Layer projects into many surfaces — the SSR'd DOM truth layer, the WebGL spectacle, the static timeline, the routes, the JSON-LD. The DOM projection is the truth; WebGL is a leaf enhancement mounted on top of it and never depended upon by it.

At runtime, every concern two scenes could each try to own — scroll, the animation loop, the camera, per-frame state, the sequence→distance mapping, history, panels, quality — has exactly one authority.

The truth layer stands alone

truth/ must build and render fully with spectacle/ absent. Résumé, dates, links, SEO — all present before the canvas exists.

AD-2 · AD-10

One data core feeds everything

The rail, a panel, a route, and the SEO fallback can never disagree about an era's band, dates, or tech — there is one canonical record, keyed by slug.

04

Deferred by design

The other half of the contract. Each is pushed down with the reason it can wait — and, where a real fork stays open, the invariant that already fences it.

§8 Q16

WebGPU at launch

WebGL2-only baseline, no WebGPU-only paths. Revisit compute-particle paths post-telemetry.

§8 Q15

Buy-vs-build the scroll rig

Topology is fixed (AD-3/AD-4); the implementation is open. Lean hand-roll with drei primitives — r3f-scroll-rig 8.15.0 is stale, React-19 unverified. Resolve behind a spike.

FR-18

Knowledge-graph ingestion

Post-MVP, offline, tool-agnostic authoring aid. Output must conform to the Career Data Layer schema — a producer, never a renderer.

FR-22–24

Full physics build

Phase 3 / post-MVP; the scope invariant is pre-committed in AD-14. An MVP idle-drift teaser is a PM call.

FR-17

Visual relationship lines

MVP ships data + "why this matters later" panel notes; rendered lines post-MVP.

§8 Q11 · ⚑

Audio

Assumption: muted-by-default, user-initiated, out of MVP. Autoplay/a11y policy needs a call.

§8 Q10

Analytics vendor & RUM

Event schema is fixed (AD-19); the privacy-first vendor, field-CWV/RUM, error tracking, and rollback are bound together later.

§8 Q12 · ⚑

Per-era fidelity

Assumption: full 3D for the two signature bookends (ground BAE, orbit→deep-space AI); lighter treatments for transitional eras. Tuned in spikes.

▸ Holes found → fixes applied

  • Accessibility had no owning rule. Flash-safety (PEAT), keyboard/never-raycast-only, focus-ring contrast, SR live-region — added as AD-16, plus an axe+PEAT CI gate.
  • Two record types could each store an era's band + years. AD-1 tightened: one canonical Era keyed by slug owns band/years; everything else references it.
  • Scroll, routing, and the router all wrote history. New AD-18 names a single navigation authority; route→placement is one-way.
  • Panels & the primary metric had no single owner. AD-17 (one panel/focus controller) and AD-19 (one analytics schema, so scroll-vs-jump arrival stays computable).
  • Fallback taxonomy & quality-monitor ownership were fuzzy. AD-14 pins the adjacent-era window + failure classes; AD-13 owns the one runtime monitor; AD-9 made surface selection deterministic.
